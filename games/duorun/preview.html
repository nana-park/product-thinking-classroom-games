게임 모음으로읽기 전용 미리보기

두런

같은 입력 작업, 다른 협업 규칙.

2명이 한글 이름 입력 작업을 수행합니다. 이 페이지는 규칙 설명이며 실제 게임이나 측정 결과가 아닙니다.

글자 나누기

첫째와 둘째 글자를 각자 입력합니다. 두 입력이 끝나면 셋째 글자가 나타나고 지정된 사람이 입력합니다.

이름 나누기

한 사람이 이름 전체를 입력한 다음, 다른 사람이 다음 이름을 입력합니다.

함께 이야기할 질문

입력할 수 있는 시간과 기다리는 시간은 어떻게 달라질까요? 일을 더 잘게 나누는 방식은 언제 도움이 될까요?

실행 조건

원본은 Worker/서버와 공유 데이터 저장소가 필요한 2인 게임입니다. 정적 HTML만으로 플레이할 수 없습니다. 현재 서비스는 비공개이며 이 미리보기는 서버에 연결하지 않습니다.
