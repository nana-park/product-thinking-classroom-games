# 같이, 키친 · Together Kitchen

Recovered unchanged from the user's existing public classroom game on 2026-10-23.

Live game: https://together-kitchen-lab.nana-the-variation.chatgpt.site

## Learning concept
Compare solo, human–human, and human–rule-based-AI collaboration in a 60-second kitchen simulation. Players collect ingredients, cook two recipes, serve customers, and clear tables. The same layout, order sequence, and duration support reflection on coordination, bottlenecks, and division of work. This is a classroom experience, not causal evidence of AI effectiveness. The AI partner is rule-based and is not connected to a generative model.

## Run
Serve this directory with any static HTTP server, for example `python -m http.server 8000`, then open http://localhost:8000. JavaScript modules require HTTP rather than opening index.html directly.

## Provenance and scope
The four unchanged public assets are index.html, style.css, app.js, and engine.js. No student records, class room codes, credentials, or server data were downloaded. This is a recovery of the public runnable assets, not the original Git repository or its test suite. Original live access and content were not modified. The public two-player mode is keyboard-based; mobile compatibility has not been newly verified.
