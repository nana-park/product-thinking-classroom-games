# Design reference

Matched to [Career Workspace](https://nana-park.github.io/job-application-strategist/), specifically its published index.html and the local company-report/index.html used to build that page. No company or personal records were copied.

- Same white page and neutral text palette (#18181b, #27272a, #71717a).
- Same Pretendard variable font, with its OFL license preserved.
- Same 1040px shell, 48px/40px desktop padding, 24px/20px mobile padding.
- Same 32px/500 desktop heading and 28px mobile heading.
- Same vertical cards, 8px radius, #e5e7eb border, subtle shadow, 32px desktop/24px mobile card padding, and 16px list gap.
- Same 22px/400 card headings. Purpose descriptions use 14px for readability; small status metadata was removed at the user’s request.
- Same outlined sorting control and full-card links; no oversized colored hero or blue call-to-action.

Game destinations and privacy boundaries are unchanged. Screenshots remain available in an expandable section so the default layout follows the reference's text-first list.

Latest copy uses one purpose-focused sentence per game and the requested genre labels. Action labels distinguish play, result preview, and rules. Implementation-status labels and the old experience notice are removed. User Inyerface is listed separately as an external classroom activity; its original URL was verified on 2026-10-23. Classroom use is confirmed by the user’s conversation and D4/D5 context supplied to this task. No other external game was included without confirmed use.
