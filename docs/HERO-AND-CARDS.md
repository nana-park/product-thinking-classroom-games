# Hero and square cards

The hero follows the composition of the user-provided visual reference: a dark illustrated game world, centered title and subtitle, two rounded calls to action, and a light transition into the content. The original reference image and its branding are not included in this repository. `assets/hero-world.png` is an original AI-generated decorative illustration, not a screenshot of any game in this collection.

The card area retains Career Workspace's Pretendard typography, neutral colors, restrained borders, and spacing. All four previews use a 1:1 frame; game screenshots use `object-fit: contain`. The external User Inyerface card uses a typographic link preview, not copied game artwork or code.

Chrome checks: desktop viewport 1280 × 1000, three columns, previews 302 × 302; mobile viewport 390 × 844, one column, previews 333 × 333. No horizontal overflow; all three screenshot assets loaded. Hero navigation and alphabetical/default sorting were checked. Existing game destinations and confirmed copy are preserved.

Screenshots: `hub-desktop.jpg`, `hub-cards-desktop.jpg`, `hub-mobile.jpg`, `hub-cards-mobile.jpg`.

The Duorun link remains a rules preview. No private service, backend, classroom data, or permissions were changed.
